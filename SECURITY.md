# Security

The sample apps never contain API keys, passwords or other credentials. Keys you enter on a sample's Setup page are stored only in your own Dataverse environment.

If you find a security issue in these samples or in Address Validation for Dataverse, please **do not open a public issue**. Email [support@sharpxrm.com](mailto:support@sharpxrm.com) with the details instead, and we will respond as quickly as we can.

If you accidentally post a provider key in an issue or pull request, rotate the key with the provider straight away, then let us know so we can delete the post.
